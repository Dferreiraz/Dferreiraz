## 🦕 DinoAtlas API

Uma API REST criada como projeto de estudo para aprofundar conhecimentos em **Backend, Node.js, APIs e organização de dados**.

O projeto tem como objetivo disponibilizar informações relacionadas à **paleontologia e dinossauros** através de uma API própria.

### 🎯 Objetivos do projeto

* Criar uma API REST
* Trabalhar com rotas
* Organizar dados
* Criar endpoints
* Trabalhar com respostas JSON
* Aprender conceitos de Backend
* Evoluir a arquitetura da aplicação

**Tecnologias:** Node.js • JavaScript • REST API • JSON

O projeto tem como foco estudar **Full Stack, banco de dados, autenticação, APIs e arquitetura de sistemas**.
